BƯỚC 1

Tạo Personal Auth Token trên Sentry

Đăng nhập vào máy chủ Sentry của công ty tại https://sentry.easypos.vn, sau đó thực hiện theo các bước sau:

  1. Nhấn vào ảnh đại diện cá nhân ở góc dưới bên trái ➔ Chọn User settings (hoặc truy cập trực tiếp Cài đặt API Tokens).
  2. Chọn mục API trong thanh menu bên trái ➔ Chọn User Auth Tokens.
  3. Bấm nút Create New Token (Tạo token mới).
  4. Đặt tên gợi nhớ cho Token (ví dụ: BotJira-Integration) và tích chọn các quyền (Scopes) tối thiểu:
    • project:read (Quyền đọc danh sách và cấu hình dự án)
    • event:read (Quyền đọc chi tiết stack trace và sự kiện lỗi)
    • issue:read (Quyền đọc danh sách lỗi unresolved)
  5. Nhấn Create Token và sao chép mã token lưu vào nơi an toàn.
Hình 1: Màn hình tạo Personal Access Token trên Sentry với các Scopes cần thiết

Chú ý: Chỉ cần tích chọn 3 quyền: project:read, event:read, issue:read. Không cần cấp quyền write hay admin.

BƯỚC 2

Xác Định Thông Tin Cần Nhập Vào Web

Bạn cần chuẩn bị 3 thông tin để nhập vào trang cài đặt:

1. Organization Slug (Tổ chức)

Lấy từ đường dẫn URL trên trình duyệt khi bạn vào Sentry:

https://sentry.easypos.vn/organizations/sentry/insights/...

➔ Trong hệ thống của bạn, Org Slug là: sentry

2. Ánh Xạ Dự Án (Sentry Slug → Key Jira)

Ghép slug dự án trên Sentry với mã Project tương ứng trên Jira:

easy-hrm:MHRM

➔ Cú pháp: slug:KEY, phân tách nhau bằng dấu phẩy nếu có nhiều dự án (tối đa 10 cặp). Ví dụ: easy-hrm:MHRM,mobile-app:EPM

Danh mục Project Jira hợp lệ: Key Jira bạn chọn phải là một trong các dự án đang được kích hoạt đồng bộ trên hệ thống (ví dụ: CICM, EDM, EMA, EPM, ETM, MHRM, MR, ECM, EIM). Đối với dự án easy-hrm, dự án Jira tương ứng là MHRM.
BƯỚC 3

Nhập Cấu Hình Trên Trang Settings Của Web App

  1. Truy cập vào ứng dụng web tại http://localhost:3100/settings ➔ Chọn mục Tích hợp cá nhân.
  2. Cuộn xuống phần Sentry:
    • Ô Organization slug: Điền sentry
    • Ô Dự án Sentry → project Jira: Điền easy-hrm:MHRM
    • Ô Sentry token: Dán mã Personal Auth Token bạn vừa tạo ở Bước 1.
  3. Bấm nút Lưu & xác minh. Hệ thống sẽ ngay lập tức gửi một yêu cầu thử nghiệm tới https://sentry.easypos.vn/api/0/projects/sentry/easy-hrm/issues/ để kiểm tra.
  4. Nếu thông tin chính xác, hệ thống sẽ hiện thông báo thành công màu xanh lá. Token của bạn được mã hóa an toàn và sẵn sàng hoạt động.
Hình 2: [Ảnh chụp thực tế web app] Mục Cài đặt ➔ Tích hợp cá nhân ➔ Sentry

Giao diện thực tế tại /settings: Điền Organization slug sentry, dự án easy-hrm:MHRM và dán Token rồi bấm Lưu & xác minh.

BƯỚC 4

Duyệt Lỗi & Tạo Task Jira Với AI Root Cause (/sentry)

Sau khi kết nối thành công, mỗi 5 phút hệ thống sẽ tự động quét các sự cố (issues) mới từ Sentry, phân tích bằng AI và đưa vào hàng chờ duyệt:

  • Truy cập trang: http://localhost:3100/sentry để xem danh sách lỗi vừa quét được.
  • Hệ thống tự động kích hoạt AI Root Cause Analysis: tóm tắt nguyên nhân gốc và gợi ý file code cần sửa.
  • Trưởng nhóm hoặc kỹ sư bấm nút "Tạo Task Jira": hệ thống sẽ tạo ngay Task trên bảng Jira tương ứng (dự án MHRM) kèm stack trace đầy đủ.
Hình 3: [Ảnh chụp thực tế web app] Trang Hàng chờ duyệt lỗi (/sentry)

Giao diện thực tế tại /sentry: Thống kê lỗi theo mức độ nghiêm trọng, bộ lọc dự án và danh sách lỗi chờ duyệt để tạo Task Jira.

Xem trước mẫu Task Jira sẽ được tự động tạo: Project: MHRM (Mobile HRM)
[Sentry] EASY-HRM-12: NullCheckOperator used on a null value in AttendanceHistoryScreen.dart:73
Labels: sentry-issue sentry-id:EASY-HRM-12

🤖 AI Root Cause Analysis:

• Nguyên nhân: Dữ liệu ca làm việc `shiftRecord.checkInTime` trả về null đối với nhân viên mới chưa có lượt chấm công nào trong tháng.

• File liên quan: `lib/features/attendance/presentation/attendance_history_screen.dart:73`

• Đề xuất xử lý: Sử dụng fallback hiển thị rỗng hoặc format date an toàn `checkInTime?.format()` thay vì toán tử bang `checkInTime!`.

Các Lỗi Thường Gặp & Cách Khắc Phục (Troubleshooting)

Hiện tượng lỗi Nguyên nhân Cách xử lý
"Project Jira ... chưa có trong danh mục" Mã Key Jira bạn nhập không nằm trong danh mục các dự án được hệ thống hỗ trợ. Đối với dự án Easy HRM, dùng Key MHRM. Nếu muốn dùng key khác, liên hệ Quản trị viên để thêm vào danh mục.
"Không đọc được dự án Sentry: 401 Unauthorized" Token Sentry không chính xác, bị hết hạn hoặc thiếu quyền đọc cần thiết. Tạo một User Auth Token mới trên sentry.easypos.vn với đủ 2 quyền project:read, event:read và dán lại.
"Không đọc được dự án Sentry: 404 Not Found" Sai Organization slug hoặc sai Slug dự án trên Sentry. Đảm bảo Organization Slug điền đúng là sentry và project slug là easy-hrm.
Lỗi không xuất hiện trong danh sách duyệt sau khi lưu Hệ thống quét định kỳ theo chu kỳ 5 phút một lần. Đợi tối đa 5 phút. Nếu vẫn không thấy, kiểm tra xem dự án trên Sentry có lỗi mới ở trạng thái "Unresolved" hay không.
