Hướng Dẫn Cấu Hình
Webhook Jira & Git Bitbucket

Thiết lập Webhook giúp Team Task Web nhận sự kiện thay đổi tức thời từ Jira Data Center (tạo, cập nhật task, đổi cột kanban) và Bitbucket Git Server (push commit, mở PR, cảnh báo merge trái phép).

Bảng Thông Số Webhook Endpoints

Hệ thống nguồn Webhook URL Endpoint Cơ chế xác thực (Auth) Biến môi trường (.env)
Jira Server / DC https://jira.kieuanhdev.id.vn/api/webhooks/jira URL param ?token=<secret> hoặc header X-Atlassian-Token JIRA_WEBHOOK_SECRET
Bitbucket Server (Git) https://jira.kieuanhdev.id.vn/api/webhooks/bitbucket HMAC SHA-256 header X-Hub-Signature: sha256=<hmac> BITBUCKET_WEBHOOK_SECRET

* Lưu ý: Nếu đang chạy trên máy local để kiểm thử, thay domain bằng http://localhost:3100 hoặc đường hầm tunnel (ngrok / cloudflare tunnel).

BƯỚC 1

Tạo Khóa Bí Mật (Secret) & Khai Báo Biến Môi Trường

Để ngăn chặn giả mạo request từ bên ngoài, mỗi nguồn (Jira và Git Bitbucket) cần một mã secret riêng biệt. Tạo ngẫu nhiên 2 chuỗi hex 32-byte bằng lệnh sau trong Terminal:

# Chạy lệnh để sinh mã ngẫu nhiên cho Jira:

$ openssl rand -hex 32

# Chạy lệnh để sinh mã ngẫu nhiên cho Bitbucket Git:

$ openssl rand -hex 32

Mở file .env của hệ thống và điền 2 giá trị vừa tạo:

JIRA_WEBHOOK_SECRET=your-jira-secret-key-hex

BITBUCKET_WEBHOOK_SECRET=your-bitbucket-secret-key-hex

Lưu ý bảo mật: Trong môi trường Production (NODE_ENV=production), hệ thống sẽ từ chối ngay lập tức (mã 401 Unauthorized) bất kỳ request webhook nào nếu chưa cấu hình secret tương ứng.
BƯỚC 2

Cấu Hình Webhook Trên Jira Server / Data Center

Đăng nhập vào Jira với quyền Quản trị viên (Jira Administrator), sau đó thực hiện:

  1. Vào biểu tượng Bánh răng (Cài đặt) ➔ Chọn System (Hệ thống).
  2. Trong thanh menu bên trái, tìm mục Advanced ➔ Chọn WebHooks.
  3. Bấm nút Create a WebHook ở góc trên bên phải.
  4. Điền các thông tin:
    • Name: Team Task Bot
    • Status: Chọn Enabled
    • URL: https://jira.kieuanhdev.id.vn/api/webhooks/jira?token=<your-jira-secret>
  5. Tại phần Events, tích chọn:
    • Issue: created, updated, deleted
    • Comment: created, updated
    • Worklog: created, updated
  6. JQL Filter (Bộ lọc dự án): Để trống để áp dụng mọi dự án, hoặc điền project in (EPM, CICM, MHRM, EDM, EMA, ETM, MR, ECM, EIM).
  7. Cuộn xuống dưới cùng và bấm Save.

BƯỚC 3

Cấu Hình Webhook Trên Bitbucket Server (Git)

Bạn có thể cấu hình ở cấp độ Project (áp dụng cho toàn bộ repository trong dự án) hoặc ở cấp độ từng Repository:

  1. Vào phần Settings của Project hoặc Repository trên Bitbucket.
  2. Chọn mục Webhooks ➔ Bấm nút Create webhook.
  3. Điền các thông tin:
    • Name: Team Task Bot
    • URL: https://jira.kieuanhdev.id.vn/api/webhooks/bitbucket
    • Secret: Điền mã <BITBUCKET_WEBHOOK_SECRET> bạn đã tạo ở Bước 1.
  4. Tại phần Events, tích chọn:
    • Repository: Tích chọn Push (refs_changed)
    • Pull request: Tích chọn toàn bộ: Opened, Modified, Merged (rất quan trọng), Declined
    • Comment: Tích chọn Comment added, Comment edited
  5. Bấm nút Test connection: Nếu nhận phản hồi 200 OK Connection Successful là chính xác!
  6. Bấm Create để hoàn tất.

TÍNH NĂNG ĐẶC BIỆT

Cảnh Báo Merge Nhánh Trái Phép Tới Project Leader

Hệ thống tích hợp cơ chế bảo vệ mã nguồn tự động qua Webhook:

1. Bắt sự kiện pr:merged

Khi có ai đó bấm Merge Pull Request trên Bitbucket, webhook gửi ngay gói tin về hệ thống bot.

2. Đối chiếu danh sách Leader

Bot kiểm tra xem người vừa merge có nằm trong danh mục Project Leader (cài đặt tại Settings ➔ Leader theo dự án) hay không.

3. Phát cảnh báo khẩn cấp

Nếu người merge không phải Leader, bot gửi thông báo tức thời qua Web Push và Discord cho các Leader của dự án đó.

BƯỚC 4

Kiểm Tra Hoạt Động (Health Check & Test Ping)

Bạn có thể kiểm tra xem webhook receiver của hệ thống có đang sống và phản hồi tốt hay không bằng lệnh cURL:

Kiểm tra endpoint Jira Webhook:
curl -i https://jira.kieuanhdev.id.vn/api/webhooks/jira
# Phản hồi: HTTP 200 {"ok":true,"source":"jira"}
Kiểm tra giả lập Bitbucket Webhook Ping:

BODY='{"eventKey":"diagnostics:ping"}'

SIG=$(printf '%s' "$BODY" | openssl dgst -sha256 -hmac "<your-bitbucket-secret>" -hex | sed 's/^.* //')

curl -i -X POST https://jira.kieuanhdev.id.vn/api/webhooks/bitbucket \

  -H "Content-Type: application/json" \

  -H "X-Hub-Signature: sha256=$SIG" \

  -d "$BODY"

Bảng Xử Lý Sự Cố Webhook (Troubleshooting)

Hiện tượng Nguyên nhân Cách khắc phục
Webhook trả về mã 401 Unauthorized Sai Secret hoặc thiếu Secret trong file .env máy chủ. Kiểm tra lại JIRA_WEBHOOK_SECRET và BITBUCKET_WEBHOOK_SECRET trong file .env và khởi động lại server.
Jira báo lỗi kết nối khi lưu Webhook Máy chủ Jira không kết nối được tới domain webhook do tường lửa (firewall) nội bộ. Mở port hoặc cấu hình proxy nội bộ cho phép server Jira gọi ra domain jira.kieuanhdev.id.vn.
Task trên web cập nhật chậm Chưa kích hoạt Webhook, hệ thống đang phải dùng cơ chế polling dự phòng (1 phút/lần). Thiết lập Webhook theo các bước trên để dữ liệu được push tức thì (real-time trong vài mili-giây).
